## The entry

> This morning my shadow on the wet pavement walked half a step ahead of me, as if it had somewhere better to be.

One sentence, 111 characters. A wet pavement, a shadow a half step ahead, and a small joke at the end: the shadow has somewhere better to be.

## How it runs

```sh
python3 main.py
```

`main.py` writes the sentence to `/output/entry.txt`. It checks the text first: 1 to 200 characters, one sentence, no leading or trailing space. The output is fixed, so every run writes the same bytes.
